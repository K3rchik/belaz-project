# Система визуализации данных БелАЗ (Цифровой двойник)

Проект по созданию системы мониторинга и анализа надежности карьерных самосвалов БелАЗ в реальном времени.

## 🛠 Технологический стек
* **Hardware:** Raspberry Pi 5 (16GB RAM) + Radxa Penta SATA HAT + SSD 128GB.
* **Database:** PostgreSQL + TimescaleDB (в Docker-контейнерах).
* **Language:** Python 3.11.
* **Logic:** Математическая модель износа на основе теории надежности.

## 🚀 Текущий функционал
1. **Симулятор АСД:** Имитирует технологические циклы (погрузка, транспортировка, разгрузка, заправка).
2. **Физическая модель:** Расчет расхода топлива в зависимости от уклона дороги, веса груза и скорости.
3. **Аналитический модуль:** Расчет остаточного ресурса двигателя в реальном времени с учетом коэффициентов нагрузки.

## 📂 Структура проекта
* `receiver.py` — генератор телеметрии и симулятор процессов.
* `analytics.py` — модуль расчета надежности и здоровья узлов.
* `docker-compose.yml` — конфигурация серверной инфраструктуры.
